# TFast Script Generation

Turn hooks into shootable scripts. Every script starts from an approved hook + a single angle.

## Script structure (15–45 seconds)

| Beat | Time | Purpose |
|---|---|---|
| Hook | 0–3s | The approved hook — visual + text + spoken line in sync |
| Problem | 3–10s | Agitate the pain in the audience's own words |
| Solution | 10–20s | Product as the answer — show, don't describe |
| Proof | 20–30s | Demo, result, testimonial, guarantee |
| CTA | last 5s | One action, spoken + on-screen |

## Angle selection

One script = one angle. Angles come from the `customers` brain section: pain, desire, objection, buying trigger. Never mix two angles in one script — the hook and the body must agree.

## Format variants

- **UGC/talking-head** — customer voice, phone camera, native feel (TikTok/Meta default).
- **Demo** — the product solving the problem in real time.
- **Story skit** — mini narrative with a turn.
- **Founder** — authority and why-we-built-it trust.

## Output

Per script: hook line, full voiceover, on-screen text per beat, shot list, caption style (dynamic subtitles where platform-native), and the CTA. Mark every claim that requires compliance review from the `brand` brain section.

## Rules

- Scripts read at natural speech pace — keep sentences short, present tense.
- Write the text overlay BEFORE the voiceover; overlays carry the hook on mute.
- One script per file/block, so production can brief it directly.
